# 接入指南

两条通道的配置方式完全不同：**QQ 是出站长连接，微信是入站 HTTP 回调**。

## 一、准备

至少要有 `DEEPSEEK_API_KEY`（<https://platform.deepseek.com>）。

```bash
cp .env.example .env
# 填 DEEPSEEK_API_KEY
```

## 二、QQ 机器人

### 2.1 建号

1. <https://q.qq.com> 用 QQ 登录 → 开发者 → 创建机器人
2. 主体选**个人**（需实名）
3. 「开发设置」里复制 `AppID` 和 `AppSecret`（Secret 只显示一次）
4. 「功能配置」开通 **单聊** 和 **群聊 @**
5. 「沙箱配置」把自己加成测试成员——**没上线前只有白名单能用**

```ini
QQ_APP_ID=102xxxxx
QQ_APP_SECRET=xxxxxx
BOT_NAME=大肥鱼
```

### 2.2 启动

```bash
docker compose up -d --build
docker compose logs -f
```

看到 `已获取 access_token` 就说明连上了。QQ 里给机器人发消息：

```
INFO  fatfish.qq: 收到 [users …E780E9] 你好
```

### 2.3 说明

- **不需要开端口、不需要域名**：长连接是出站的
- 被动回复窗口是 **5 分钟、最多 5 条**，所以回答慢不影响
- 发图需要两步：上传素材 → 发 `msg_type=7`

## 三、微信公众号

### 3.1 为什么公众号更麻烦

微信没有长连接，只能由微信 POST 到你的公网地址，且有硬限制：

```
用户发消息 → 5 秒内必须响应一次 → 这一轮结束
```

DeepSeek 生成通常 5~10 秒，直连必超时。所以流程是：

```
收到消息 → 立刻回「收到，正在想…」   ← 占住 5 秒窗口
        → 后台生成
        → 用客服消息推真正的答案      ← 用户发消息后 48 小时内有效
```

**客服消息需要 `AppSecret`**，所以测试号/正式号都要填。

### 3.2 拿测试号

<https://mp.weixin.qq.com/debug/cgi-bin/sandbox?t=sandbox/login> 扫码登录，页面直接给：

```
appID       wx1a2b3c...
appsecret   a1b2c3d4...
```

```ini
WECHAT_TOKEN=dafeiyu2026      # 自己定，等下后台要填一样的
WECHAT_APP_ID=wx...
WECHAT_APP_SECRET=...
```

### 3.3 配置顺序（重要）

**先起服务，再去后台点提交**。微信点「提交」时会立刻发一个 GET 验证：

```
GET /wechat?signature=...&timestamp=...&nonce=...&echostr=random
```

服务没起来，必然「配置失败」。

```bash
docker compose up -d --build
curl -s "http://127.0.0.1/wechat?signature=x&timestamp=1&nonce=1&echostr=y"
# 返回 invalid signature 就说明服务活着
```

然后再填：

```
URL    http://你的IP/wechat
Token  dafeiyu2026
```

点提交 → 「提交成功」→ 页面上扫码关注测试号 → 发消息测试。

### 3.4 前置条件

| 项 | 说明 |
|---|---|
| 端口 | 必须是 80 或 443 |
| 域名 | 用 IP 即可，**不需要备案**（备案是给域名的）；部分账号会强制要求域名 |
| Token | 两边必须完全一致 |

## 四、验证清单

| # | 操作 | 期望 |
|---|---|---|
| 1 | QQ 私聊「你好」 | 收到回复 |
| 2 | QQ 群 @ 机器人 | 收到回复 |
| 3 | 「今天天气怎么样」→ 说城市 | 给出真实气温 |
| 4 | 「画一只戴墨镜的橘猫」 | 文字 + 图片 |
| 5 | 「1 分钟后提醒我喝水」 | 回复时间 + 到点收到推送 |
| 6 | 微信「你好」 | 「收到，正在想…」+ 答案 |

第 5 条如果只有回复没有推送，看日志：

```
ERROR fatfish.scheduler: 提醒发送失败（可能是没开通主动消息权限）
```

去 q.qq.com 申请「主动消息」，代码不用改。
